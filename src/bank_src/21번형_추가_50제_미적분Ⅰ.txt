01. 정답 $216$
$g ( x )$ 가 $x = t$ 에서 연속이므로 $- f ( t ) = f ( t )$ , 즉 $f ( t ) = 0$ 이다. $x = t$ 에서의 좌미분계수는 $- f ' ( t )$ , 우미분계수는 $f ' ( t )$ 이므로 미분가능하려면 $f ' ( t ) = 0$ 이다.
따라서 $f ( x ) = ( x - t ) ^{2} ( x - s )$ 꼴이다. $g ( x ) = 0$ 의 실근은 $f ( x ) = 0$ 의 실근과 같으므로 $s neq t$ 이면 실근이 $2$ 개가 된다. 따라서 $s = t$ , $f ( x ) = ( x - t ) ^{3}$ 이고 $g ( x ) = LEFT | x - t RIGHT | ^{3}$ 이다.
$g ( 0 ) = LEFT | t RIGHT | ^{3} = 8$ 에서 $t = +- 2$ , $g ( 1 ) = LEFT | 1 - t RIGHT | ^{3} = 27$ 에서 $t = - 2$ 또는 $t = 4$ 이므로 $t = - 2$ 이다.
따라서 $g ( 4 ) = 6 ^{3} = 216$ 이다.
02. 정답 $45$
$f ( x )$ 는 $x = 1$ , $x = 3$ 의 좌우에서 부호가 바뀌므로 ${LEFT | f ( x ) RIGHT |} over {f ( x )}$ 는 이 두 점에서 $- 1$ 과 $1$ 사이를 오간다. 첫 번째 극한이 존재하려면 $g ( 1 ) = g ( 3 ) = 0$ 이어야 하므로 $g ( x ) = ( x - 1 ) ( x - 3 ) ( x - c )$ 이다.
$c neq 1$ , $c neq 3$ 이면 $g ( x )$ 는 $x = c$ 의 좌우에서 부호가 바뀌는데 $f ( c ) neq 0$ 이므로 두 번째 극한이 $x = c$ 에서 존재하지 않는다. 따라서 $c = 1$ 또는 $c = 3$ 이다. 이때 $g ( x )$ 의 부호가 바뀌는 점은 $f ( x ) = 0$ 인 점뿐이므로 두 극한은 모두 존재한다.
$c = 1$ 이면 $g ( 2 ) = - 1 < 0$ , $c = 3$ 이면 $g ( 2 ) = 1 > 0$ 이므로 $g ( x ) = ( x - 1 ) ( x - 3 ) ^{2}$ 이다.
따라서 $g ( 6 ) = 5 times 9 = 45$ 이다.

04. 정답 $21$

05. 정답 $40$
$t geq 3$ 에서 $v ( t ) = t ^{2} - 2 t + C$ 이고 $v ( 3 ) = 0$ 이므로 $C = - 3$ , 즉 $v ( t ) = ( t - 3 ) ( t + 1 ) geq 0$ 이다.

06. 정답 $32$
