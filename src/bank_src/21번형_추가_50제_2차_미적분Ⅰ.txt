01. 정답 $11$
주제: 구간의 길이가 일정한 정적분 함수의 극값
$g ' ( x ) = f ( x + 2 ) - f ( x )$ 의 최고차항은 $6 x ^{2}$ 이므로 $g ' ( x ) = 6 ( x + 1 ) ( x - 1 )$ 이다.
$x = -1$ 에서 극대, $x = 1$ 에서 극소이고 극댓값과 극솟값의 차는 $- int _{- 1} ^{1} g ' ( x ) dx = {6 times 2 ^{3}} over {6} = 8$ 이다.
극댓값은 $3 + 8 = 11$
