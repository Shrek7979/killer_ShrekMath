KAIST 일반전형 모의 면접 문제 (수학)
[문항 1]
자연수의 표현에 대하여 다음과 같이 정의한다.
TBL
  <정의> 자연수 $n$ 을 연속한 둘 이상의 자연수의 합으로 나타낼 수 있을 때, 그렇게 나타낸 식을 $n$ 의 연속합 표현이라 한다. 더하는 수들이 같으면 같은 표현으로 본다.
/TBL
예를 들어 $9 = 4 + 5 = 2 + 3 + 4$ 이므로 $9$ 의 연속합 표현은 $2$ 가지이다.
(1) $15$ 의 연속합 표현을 모두 구하시오. [1점]
(2) 다음 두 명제의 참, 거짓을 각각 판별하고 그 이유를 설명하시오. [2점]
TBL
  (가) $3$ 이상의 모든 홀수는 연속합 표현을 갖는다.
  (나) 자연수 $k$ 에 대하여 $2 ^{k}$ 은 연속합 표현을 갖지 않는다.
/TBL
(3) 자연수 $n$ 의 연속합 표현의 개수는 $n$ 의 양의 약수 중 $1$ 보다 큰 홀수의 개수와 같음을 보이고, $2025$ 의 연속합 표현의 개수를 구하시오. [2점]
[문항 2]
함수 $f ( x ) = ln`x$ $( x > 0 )$ 의 그래프를 이용하여 $n !$ 의 크기를 어림하려고 한다. $a$ , $b$ 는 $0 < a < b$ 인 실수이다.
[그림]
[그림] 곡선 $y = ln`x$ 와 이 곡선 위의 두 점을 이은 선분, 그리고 곡선 위의 한 점에서의 접선
(1) 다음 두 명제의 참, 거짓을 각각 판별하고 그 이유를 설명하시오. [1점]
TBL
  (가) $ln {a + b} over {2} > {ln`a + ln`b} over {2}$
  (나) $int _{a} ^{b} ln`xdx > ( b - a ) ln {a + b} over {2}$
/TBL
(2) 부등식 $int _{a} ^{b} ln`xdx > {( b - a ) ( ln`a + ln`b )} over {2}$ 가 성립함을 보이시오. [2점]
(3) 모든 자연수 $n$ 에 대하여 부등식
$e LEFT ( {n} over {e} RIGHT ) ^{n} leq n ! leq e sqrt {n} LEFT ( {n} over {e} RIGHT ) ^{n}$
이 성립함을 보이고, 극한값 $lim _{n -> infty} {root {n} of {n !}} over {n}$ 을 구하시오. [2점] (단, $lim _{n -> infty} {ln`n} over {n} = 0$ 임은 증명 없이 이용할 수 있다.)

정답 한눈에 보기
문항 1: (1) $7 + 8$ , $4 + 5 + 6$ , $1 + 2 + 3 + 4 + 5$ (2) (가) 참, (나) 참 (3) 증명, $14$
문항 2: (1) (가) 참, (나) 거짓 (2) 증명 (3) 증명, 극한값 ${1} over {e}$
예시 답안
[문항 1]
자연수 $a$ 부터 시작하는 연속한 $k$ 개의 자연수의 합은 ${k ( 2 a + k - 1 )} over {2}$ 이다. 따라서 $n$ 의 연속합 표현은
$2 n = k ( 2 a + k - 1 )$
을 만족시키는 자연수 $a$ 와 $2$ 이상의 자연수 $k$ 의 순서쌍 $( a ,~k )$ 와 하나씩 대응한다. 이 등식을 ㉠이라 하자.
(1) $2 n = 30$ 이다. ㉠에서 $k geq 2$ 이고 $2 a + k - 1 > k$ 이므로 $k ^{2} < 30$ , 즉 $k leq 5$ 이다. $k = 2$ 이면 $2 a + 1 = 15$ 에서 $a = 7$ , $k = 3$ 이면 $2 a + 2 = 10$ 에서 $a = 4$ , $k = 5$ 이면 $2 a + 4 = 6$ 에서 $a = 1$ 이고, $k = 4$ 이면 $30$ 이 $4$ 의 배수가 아니므로 해가 없다. 따라서 $15$ 의 연속합 표현은 $7 + 8$ , $4 + 5 + 6$ , $1 + 2 + 3 + 4 + 5$ 의 $3$ 가지이다.
(2) (가) 참이다. $3$ 이상의 홀수는 자연수 $m$ 에 대하여 $2 m + 1$ 로 쓸 수 있고 $2 m + 1 = m + ( m + 1 )$ 이므로 연속한 두 자연수의 합이다.
(나) 참이다. $2 ^{k}$ 이 연속합 표현을 갖는다고 하면 ㉠에서 $2 ^{k + 1} = j ( 2 a + j - 1 )$ 인 자연수 $a$ 와 $2$ 이상의 자연수 $j$ 가 존재한다. 두 수 $j$ 와 $2 a + j - 1$ 의 합 $2 a + 2 j - 1$ 은 홀수이므로 둘 중 하나는 홀수이다. $j geq 2$ 이고 $2 a + j - 1 geq 3$ 이므로 그 홀수는 $1$ 보다 크다. 그런데 $2 ^{k + 1}$ 의 양의 약수 중 홀수는 $1$ 뿐이므로 모순이다. 따라서 $2 ^{k}$ 은 연속합 표현을 갖지 않는다.
(3) ㉠에서 $s = 2 a + k - 1$ 이라 하면 $2 n = ks$ 이고, $a geq 1$ 이므로 $s > k geq 2$ 이며, $k + s = 2 a + 2 k - 1$ 이 홀수이므로 $k$ 와 $s$ 중 하나는 홀수이고 다른 하나는 짝수이다. 거꾸로 $2 n = ks$ 이고 $2 leq k < s$ 이며 $k$ 와 $s$ 의 홀짝이 다른 자연수 $k$ , $s$ 가 주어지면 $a = {s - k + 1} over {2}$ 은 자연수이고 ㉠이 성립한다. 따라서 $n$ 의 연속합 표현의 개수는 이러한 순서쌍 $( k ,~s )$ 의 개수와 같다.
이제 $n$ 의 양의 약수 중 $1$ 보다 큰 홀수 $t$ 에 대하여 두 수 $t$ 와 ${2 n} over {t}$ 을 생각하자. $t$ 는 홀수이고 ${2 n} over {t}$ 은 짝수이므로 두 수는 서로 다르다. 둘 중 작은 수를 $k$ , 큰 수를 $s$ 라 하면 $t geq 3$ , ${2 n} over {t} geq 2$ 이므로 $2 leq k < s$ 이고 $2 n = ks$ 이며 $k$ 와 $s$ 의 홀짝이 다르다.
거꾸로 위의 조건을 만족시키는 순서쌍 $( k ,~s )$ 가 주어지면 $k$ 와 $s$ 중 홀수인 것을 $t$ 라 할 때, $t$ 는 $2 n$ 의 약수인 홀수이므로 $n$ 의 약수이고, $k geq 2$ , $s geq 3$ 에서 $t > 1$ 이다. 이 두 대응은 서로 거꾸로이므로 순서쌍 $( k ,~s )$ 와 $n$ 의 $1$ 보다 큰 홀수인 약수 $t$ 는 하나씩 대응한다. 따라서 $n$ 의 연속합 표현의 개수는 $n$ 의 양의 약수 중 $1$ 보다 큰 홀수의 개수와 같다.
$2025 = 3 ^{4} times 5 ^{2}$ 의 양의 약수는 모두 홀수이고 그 개수는 $5 times 3 = 15$ 이다. 이 중 $1$ 을 제외하면 $14$ 개이므로 $2025$ 의 연속합 표현의 개수는 $14$ 이다.
[문항 2]
$f ( x ) = ln`x$ 에서 $f ' ( x ) = {1} over {x}$ , $f ' ' ( x ) = - {1} over {x ^{2}} < 0$ 이다. 다음 두 사실을 먼저 보인다.
사실 1. $c > 0$ 일 때, $x > 0$ 인 모든 실수 $x$ 에 대하여 $ln`x leq ln`c + {x - c} over {c}$ 이고 등호는 $x = c$ 일 때만 성립한다. 즉 곡선 $y = ln`x$ 는 곡선 위의 점에서의 접선보다 위쪽에 있지 않다.
(증명) $u ( x ) = ln`c + {x - c} over {c} - ln`x$ 라 하면 $u ' ( x ) = {1} over {c} - {1} over {x}$ 이므로 $u ( x )$ 는 $0 < x < c$ 에서 감소하고 $x > c$ 에서 증가한다. $u ( c ) = 0$ 이므로 $u ( x ) geq 0$ 이고 등호는 $x = c$ 일 때만 성립한다.
사실 2. $a < x < b$ 일 때 $ln`x > ln`a + {ln`b - ln`a} over {b - a} ( x - a )$ 이다. 즉 곡선 $y = ln`x$ 는 두 점 $( a ,~ln`a )$ , $( b ,~ln`b )$ 를 이은 선분보다 위쪽에 있다.
(증명) $v ( x ) = ln`x - ln`a - {ln`b - ln`a} over {b - a} ( x - a )$ 라 하면 $v ( a ) = v ( b ) = 0$ 이고 $v ' ( x ) = {1} over {x} - {ln`b - ln`a} over {b - a}$ 는 감소한다. 롤의 정리에 의하여 $v ' ( x _{0} ) = 0$ 인 $x _{0}$ 이 $a$ 와 $b$ 사이에 존재하고, $v ' ( x )$ 가 감소하므로 $a < x < x _{0}$ 에서 $v ' ( x ) > 0$ , $x _{0} < x < b$ 에서 $v ' ( x ) < 0$ 이다. 따라서 $v ( x )$ 는 $a leq x leq x _{0}$ 에서 증가하고 $x _{0} leq x leq b$ 에서 감소하므로 $a < x < b$ 에서 $v ( x ) > 0$ 이다.
(1) (가) 참이다. 사실 2에서 $x = {a + b} over {2}$ 를 대입하면 $ln {a + b} over {2} > ln`a + {ln`b - ln`a} over {2} = {ln`a + ln`b} over {2}$ 이다.
(나) 거짓이다. $c = {a + b} over {2}$ 라 하면 사실 1에 의하여 $ln`x leq ln`c + {x - c} over {c}$ 이고 등호는 $x = c$ 일 때만 성립하므로
$int _{a} ^{b} ln`xdx < int _{a} ^{b} LEFT ( ln`c + {x - c} over {c} RIGHT ) dx = ( b - a ) ln`c$
이다. ( $int _{a} ^{b} ( x - c ) dx = 0$ 이기 때문이다.) 따라서 $int _{a} ^{b} ln`xdx < ( b - a ) ln {a + b} over {2}$ 이고, 명제 (나)는 거짓이다.
(2) 사실 2의 부등식의 양변을 $a$ 에서 $b$ 까지 적분하면
$int _{a} ^{b} ln`xdx > ( b - a ) ln`a + {ln`b - ln`a} over {b - a} cdot {( b - a ) ^{2}} over {2} = {( b - a ) ( ln`a + ln`b )} over {2}$
이다.
(3) $int _{1} ^{n} ln`xdx = LEFT [ x ln`x - x RIGHT ] _{1} ^{n} = n ln`n - n + 1$ 이다.
$n = 1$ 일 때 주어진 부등식의 세 변은 모두 $1$ 이므로 성립한다. $n geq 2$ 라 하자.
오른쪽 부등식: (2)에서 $a = k$ , $b = k + 1$ 로 두면 ${ln`k + ln ( k + 1 )} over {2} < int _{k} ^{k + 1} ln`xdx$ 이다. $k = 1 ,~2 ,~cdots ,~n - 1$ 에 대하여 변끼리 더하면 좌변은 $ln`1 + ln`2 + cdots + ln`n - {ln`1 + ln`n} over {2} = ln`n ! - {1} over {2} ln`n$ 이므로
$ln`n ! - {1} over {2} ln`n < n ln`n - n + 1$
이다. 따라서 $n ! < e sqrt {n} LEFT ( {n} over {e} RIGHT ) ^{n}$ 이다.
왼쪽 부등식: $ln`x$ 는 증가하므로 $k geq 2$ 일 때 $int _{k - 1} ^{k} ln`xdx < ln`k$ 이다. $k = 2 ,~3 ,~cdots ,~n$ 에 대하여 변끼리 더하면
$n ln`n - n + 1 < ln`2 + ln`3 + cdots + ln`n = ln`n !$
이다. 따라서 $n ! > e LEFT ( {n} over {e} RIGHT ) ^{n}$ 이다.
이상에서 모든 자연수 $n$ 에 대하여 주어진 부등식이 성립한다.
부등식의 각 변에 자연로그를 취하고 $n$ 으로 나눈 뒤 $ln`n$ 을 빼면
${1} over {n} - 1 leq ln {root {n} of {n !}} over {n} leq {1} over {n} + {ln`n} over {2 n} - 1$
이다. $n -> infty$ 일 때 양 끝의 식은 모두 $- 1$ 에 수렴하므로 $lim _{n -> infty} ln {root {n} of {n !}} over {n} = - 1$ 이고, 지수함수는 연속이므로
$lim _{n -> infty} {root {n} of {n !}} over {n} = {1} over {e}$
이다.
