KAIST 일반전형 면접 대비 문제 (수학) 1~10회
각 회는 수학 2문항이며, 시험 시간은 20분을 기준으로 합니다. 문항마다 5점 만점으로 소문항별 배점을 표시하였습니다. 모든 문항을 실제 기출보다 어려운 최고난도 수준으로 구성하였습니다.
제1회
[문항 1]
수열 $LBRACE a _{n} RBRACE$ 이
$a _{1} = 1 ,~a _{n + 1} = a _{n} ^{2} + 1$
과 같이 귀납적으로 정의된다. (단, $n$ 은 자연수이다.)
(1) 다음 두 명제의 참, 거짓을 각각 판별하고 그 이유를 설명하시오. [1점]
TBL
  (가) $n$ 이 $3$ 의 배수이면 $a _{n}$ 은 $5$ 의 배수이다.
  (나) $a _{n}$ 이 $25$ 의 배수가 되는 자연수 $n$ 이 존재한다.
/TBL
(2) 두 자연수 $k$ , $n$ 에 대하여 $a _{n}$ 이 $a _{k}$ 의 배수이기 위한 필요충분조건은 $n$ 이 $k$ 의 배수인 것임을 보이시오. [2점]
(3) $a _{2025}$ 와 $LEFT ( a _{2028} RIGHT ) ^{2}$ 의 최대공약수를 구하시오. [2점]
[문항 2]
평면 위의 두 원에 대하여 다음과 같이 정의한다.
TBL
  <정의> 두 원이 서로 다른 두 점에서 만나고, 각 교점에서 두 원의 접선이 서로 수직일 때, 두 원은 서로 직교한다고 한다.
/TBL
(1) 반지름의 길이가 각각 $r _{1}$ , $r _{2}$ 이고 중심 사이의 거리가 $d$ 인 두 원이 직교하기 위한 필요충분조건은 $d ^{2} = r _{1} ^{2} + r _{2} ^{2}$ 임을 설명하시오. [1점]
(2) 두 원 $C _{1} : x ^{2} + y ^{2} = 1$ , $C _{2} : ( x - 4 ) ^{2} + y ^{2} = 4$ 와 모두 직교하는 원의 중심 전체의 집합을 구하고, 이 원들이 모두 공통으로 지나는 점을 모두 구하시오. [2점]
[그림]

(3) 두 원 $C _{1}$ , $C _{2}$ 와 모두 직교하고 직선 $y = x$ 에 접하는 원의 개수와 각 원의 반지름의 길이를 구하시오. [2점]
제2회
[문항 1]
좌표평면의 원점에 로봇이 놓여 있고, 처음에 로봇은 $x$ 축의 양의 방향을 바라보고 있다. 앞면과 뒷면이 나올 확률이 각각 ${1} over {2}$ 인 동전을 던질 때마다 로봇은 다음 규칙에 따라 움직인다.
TBL
  <규칙> 앞면이 나오면 로봇은 바라보는 방향으로 $1$ 만큼 이동한다. 뒷면이 나오면 로봇은 이동하지 않고 제자리에서 시계 반대 방향으로 $120 DEG$ 만큼 회전한다.
/TBL
[그림]
[그림] 동전이 앞, 앞, 뒤, 앞, 뒤, 앞의 순서로 나왔을 때 로봇이 움직인 길
동전을 $N$ 번 던진 뒤 로봇이 원점에 있을 확률을 $P _{N}$ 이라 하자.
(1) $P _{5}$ 와 $P _{6}$ 을 각각 구하시오. [1점]
(2) $P _{11}$ 을 구하시오. 또 동전을 $11$ 번 던진 뒤 로봇이 원점에 있었을 때, 앞면이 정확히 $3$ 번 나왔을 확률을 구하시오. [2점]
(3) $m$ 은 자연수이다. 동전을 $3 m + 2$ 번 던질 때, 앞면이 정확히 $r$ 번 나오고 로봇이 원점에 있을 확률을 $p _{r}$ 라 하자. $p _{r}$ 를 $m$ 과 $r$ 에 대한 식으로 나타내고, $p _{r}$ 가 최대가 되도록 하는 $r$ 의 값을 모두 구하시오. [2점]
[문항 2]
자연수 $n$ 에 대하여 함수 $f _{n} ( x )$ 를
$f _{n} ( x ) = x ^{3} - nx ^{2} + ( n - 3 ) x + 1$
이라 하자.

TBL

/TBL
(2) 방정식 $f _{n} ( x ) = 0$ 의 한 근을 $alpha$ 라 할 때 ${1} over {1 - alpha}$ 도 이 방정식의 근임을 보이고, 이를 이용하여 방정식 $f _{n} ( x ) = 0$ 이 서로 다른 세 실근을 가짐을 보이시오. [2점]
(3) 방정식 $f _{n} ( x ) = 0$ 의 세 실근을 작은 것부터 차례로 $gamma _{n}$ , $alpha _{n}$ , $beta _{n}$ 이라 할 때, 등식
$( beta _{n} - alpha _{n} ) ( beta _{n} - gamma _{n} ) ( alpha _{n} - gamma _{n} ) = n ^{2} - 3 n + 9$
가 성립함을 보이고, $lim _{n -> infty} n ( beta _{n} - n + 1 )$ 의 값을 구하시오. [2점]

/TBL

제4회
[문항 1]
$n$ , $k$ 는 $k leq n$ 인 자연수이다. $1$ 부터 $n$ 까지의 자연수가 하나씩 적힌 카드 $n$ 장과 $1$ 부터 $k$ 까지의 자연수가 하나씩 적힌 상자 $k$ 개가 있다. $n$ 장의 카드 중에서 $k$ 장을 골라 $k$ 개의 상자에 한 장씩 넣는다.
TBL
  <정의> 모든 상자에 대하여 상자에 적힌 수와 그 상자에 넣은 카드에 적힌 수가 서로 다르도록 카드를 넣는 방법의 수를 $N ( n ,~k )$ 라 한다. 또 $D _{n} = N ( n ,~n )$ 이라 한다.
/TBL
예를 들어 $N ( 2 ,~1 ) = 1$ , $D _{1} = 0$ , $D _{2} = 1$ 이다.
(1) $n geq 2$ 일 때 $N ( n ,~2 )$ 를 $n$ 에 대한 식으로 나타내고, $N ( 5 ,~3 )$ 의 값을 구하시오. [1점]
(2) 다음 두 명제의 참, 거짓을 각각 판별하고 그 이유를 설명하시오. [2점]
TBL
  (가) $2$ 이상의 모든 자연수 $n$ 에 대하여 $N ( n ,~n - 1 ) = N ( n ,~n )$ 이다.
  (나) $3 leq k leq n$ 인 모든 자연수 $n$ , $k$ 에 대하여 $N ( n ,~k ) = ( n - 1 ) N ( n - 1 ,~k - 1 ) + ( k - 1 ) N ( n - 2 ,~k - 2 )$ 이다.
/TBL
(3) $n geq 3$ 일 때 $N ( n ,~n - 1 )$ 과 $N ( n ,~n - 2 )$ 를 각각 $n$ , $D _{n}$ , $D _{n + 1}$ 에 대한 식으로 나타내시오. 또 $7$ 장의 카드 중에서 $5$ 장을 골라 $5$ 개의 상자에 한 장씩 넣는 모든 방법 중에서 하나를 임의로 택할 때, 모든 상자에 대하여 상자에 적힌 수와 그 상자에 넣은 카드에 적힌 수가 서로 다를 확률을 구하시오. [2점]
[문항 2]
$x > 0$ 에서 정의된 함수 $g ( x )$ 를
$g ( x ) = {1} over {ln`LEFT ( 1 + {1} over {x} RIGHT )} - x$
라 하자.
(1) $x > 0$ 일 때 부등식 $x - {x ^{2}} over {2} < ln ( 1 + x ) < x - {x ^{2}} over {2} + {x ^{3}} over {3}$ 이 성립함을 보이시오. [1점]
[그림]
[그림] 곡선 $y = ln ( 1 + x )$ 와 두 곡선 $y = x - {x ^{2}} over {2}$ , $y = x - {x ^{2}} over {2} + {x ^{3}} over {3}$
(2) 함수 $g ( x )$ 가 $x > 0$ 에서 증가함을 보이고, $lim _{x -> infty} g ( x )$ 의 값을 구하시오. [2점]
(3) 모든 자연수 $n$ 에 대하여 부등식
$LEFT ( 1 + {1} over {n} RIGHT ) ^{n + a} leq e leq LEFT ( 1 + {1} over {n} RIGHT ) ^{n + b}$
이 성립하도록 하는 실수 $a$ 의 최댓값과 실수 $b$ 의 최솟값을 각각 구하시오. 또 극한값 $lim _{n -> infty} n LEFT { e - LEFT ( 1 + {1} over {n} RIGHT ) ^{n} RIGHT }$ 을 구하시오. [2점]
제5회
[문항 1]
평면 위의 삼각형 $rm O A B it$ 가
$LEFT | vec {rm O A it} RIGHT | = 8 ,~LEFT | vec {rm O B it} RIGHT | = 5 ,~vec {rm O A it} cdot vec {rm O B it} = 32$
를 만족시킨다. 삼각형 $rm O A B it$ 의 변과 내부로 이루어진 도형을 $T$ 라 하자.
TBL
  <정의> 평면 위의 점 $rm X it$ 에 대하여, 점 $rm X it$ 와 도형 $T$ 에 속하는 점 사이의 거리의 최솟값을 $m ( rm X it )$ , 최댓값을 $M ( rm X it )$ 라 한다. (점 $rm X it$ 가 $T$ 에 속하면 $m ( rm X it ) = 0$ 이다.)
  이때 중심이 $rm X it$ 이고 반지름의 길이가 $r$ 인 원이 도형 $T$ 와 만나기 위한 필요충분조건은 $m ( rm X it ) leq r leq M ( rm X it )$ 이다. 이 사실은 증명 없이 이용할 수 있다.
/TBL
[그림]
[그림] 도형 $T$ 와 만나는 원의 예
(1) $vec {rm O Q it} = 2 vec {rm O B it}$ 인 점 $rm Q it$ 에서 직선 $rm A B it$ 에 내린 수선의 발을 $rm H it$ 라 하자. $vec {rm O H it}$ 를 $vec {rm O A it}$ , $vec {rm O B it}$ 로 나타내고, $m ( rm Q it )$ 와 $M ( rm Q it )$ 의 값을 각각 구하시오. [1점]
TBL
  점 $rm X it$ 가 평면 전체를 움직일 때, $M ( rm X it )$ 가 최소가 되는 점 $rm X it$ 는 삼각형 $rm O A B it$ 의 외접원의 중심이다.
/TBL
(2) 위 명제의 참, 거짓을 판별하고 그 이유를 설명하시오. 또 $M ( rm X it )$ 의 최솟값을 구하고, 그때의 $vec {rm O X it}$ 를 $vec {rm O A it}$ , $vec {rm O B it}$ 로 나타내시오. [2점]
(3) 양수 $r$ 에 대하여, 반지름의 길이가 $r$ 인 원이 도형 $T$ 와 만나도록 하는 원의 중심 전체가 나타내는 도형의 넓이를 $S ( r )$ 라 하자. $0 < r leq 4$ 일 때 $S ( r )$ 를 $r$ 에 대한 식으로 나타내고, $r > 4$ 일 때 $S ( r ) < pi r ^{2} + 18 r + 12$ 임을 보이시오. [2점]
[문항 2]
$x geq 0$ 에서 정의된 함수 $f ( x ) = e ^{- x} sin x$ 가 있다. $0$ 이상의 실수 $t$ 에 대하여
$W ( t ) = pi int _{0} ^{t} LEFT { f ( x ) RIGHT } ^{2} dx$
라 하자. 즉, $W ( t )$ 는 곡선 $y = f ( x )$ ( $0 leq x leq t$ )와 $x$ 축 및 직선 $x = t$ 로 둘러싸인 부분을 $x$ 축의 둘레로 회전시켜 생기는 입체의 부피이다. 또 자연수 $k$ 에 대하여 $V _{k} = W ( k pi ) - W ( ( k - 1 ) pi )$ 라 하자.
(1) $V _{k}$ 를 $k$ 에 대한 식으로 나타내고, 급수 $sum _{k = 1} ^{infty} V _{k}$ 의 합을 구하시오. [1점]
(2) $n$ 은 $2$ 이상의 자연수이다. 곡선 $y = f ( x )$ ( $0 leq x leq pi$ )와 $x$ 축으로 둘러싸인 부분을 $x$ 축의 둘레로 회전시켜 생기는 입체를 $x$ 축에 수직인 $n - 1$ 개의 평면으로 잘라 부피가 모두 같은 $n$ 개의 입체로 나눈다. 이 평면들이 $x$ 축과 만나는 점의 $x$ 좌표 중 가장 작은 것을 $s _{n}$ , 가장 큰 것을 $t _{n}$ 이라 할 때, 두 극한값
$lim _{n -> infty} n LEFT ( s _{n} RIGHT ) ^{3} ,~lim _{n -> infty} {pi - t _{n}} over {s _{n}}$
을 각각 구하시오. [2점]
(3) (1)에서 구한 급수의 합을 $V$ 라 하자. $2$ 이상의 자연수 $n$ 에 대하여 $W ( u _{n} ) = LEFT ( 1 - {1} over {n} RIGHT ) V$ 를 만족시키는 양수 $u _{n}$ 이 단 하나 존재함을 보이고, 극한값 $lim _{n -> infty} {u _{n}} over {ln`n}$ 을 구하시오. [2점]
제6회
[문항 1]

를 생각한다.
(1) 다음 두 명제의 참, 거짓을 각각 판별하고 그 이유를 설명하시오. [1점]
TBL

  (나) 방정식 $LEFT | f ( x ) RIGHT | = c$ 의 서로 다른 실근의 개수가 정확히 $5$ 인 삼차다항식 $f ( x )$ 와 양수 $c$ 는 존재하지 않는다.
/TBL
(2) 방정식 $LEFT | f ( x ) RIGHT | = c$ 가 서로 다른 여섯 실근을 가질 때, 이 여섯 실근을 작은 것부터 차례로 $x _{1}$ , $x _{2}$ , $x _{3}$ , $x _{4}$ , $x _{5}$ , $x _{6}$ 이라 하자. 다음 두 등식이 성립함을 보이시오. [2점]
$x _{1} + x _{4} + x _{5} = x _{2} + x _{3} + x _{6} ,~x _{1} ^{2} + x _{4} ^{2} + x _{5} ^{2} = x _{2} ^{2} + x _{3} ^{2} + x _{6} ^{2}$

[문항 2]

$x vec {u _{0}} + y vec {u _{1}} + z vec {u _{2}} = ( x - z ) vec {u _{0}} + ( y - z ) vec {u _{1}}$
이고, $vec {u _{0}}$ , $vec {u _{1}}$ 은 서로 평행하지 않으므로 로봇이 원점에 있을 조건은 $x = y = z$ 이다. 이때 앞면이 나온 횟수는 $3 k$ ( $k$ 는 $0$ 이상의 정수)이고 각 방향으로 $k$ 번씩 이동한다.
뒷면이 $t$ 번 나오면 동전을 던진 순서는 뒷면을 경계로 $t + 1$ 개의 구간으로 나뉘고, 앞에서부터 $j$ 번째 구간에서 로봇이 바라보는 방향은 $j - 1$ 을 $3$ 으로 나눈 나머지에 따라 정해진다. 앞면과 뒷면의 배열은 각 구간에 넣는 앞면의 개수로 정해진다.

제4회 예시 답안
[문항 1]
아래에서 다음 사실을 쓴다. 상자가 $a$ 개, 카드가 $b$ 장이고 각 상자마다 '넣으면 안 되는 카드'가 서로 다른 한 장씩 정해져 있으면, 그 조건을 지키며 넣는 방법의 수는 카드와 상자에 적힌 수를 바꾸어 붙여도 달라지지 않으므로 $N ( b ,~a )$ 이다.
(1) 두 상자에 카드를 넣는 방법은 모두 $n ( n - 1 )$ 가지이다. 이 중 상자 $1$ 에 카드 $1$ 을 넣는 방법은 $n - 1$ 가지, 상자 $2$ 에 카드 $2$ 를 넣는 방법은 $n - 1$ 가지이고, 두 경우에 모두 해당하는 방법은 $1$ 가지이다. 따라서
$N ( n ,~2 ) = n ( n - 1 ) - 2 ( n - 1 ) + 1 = n ^{2} - 3 n + 3$
이다.
카드 $5$ 장 중 $3$ 장을 세 상자에 넣는 방법은 모두 $5 cdot 4 cdot 3 = 60$ 가지이다. 상자 $i$ 에 카드 $i$ 를 넣는 방법은 $i = 1 ,~2 ,~3$ 각각에 대하여 $4 cdot 3 = 12$ 가지, 두 상자에서 동시에 수가 같은 방법은 상자 두 개를 고르는 $3$ 가지 경우 각각에 대하여 $3$ 가지, 세 상자에서 모두 수가 같은 방법은 $1$ 가지이다. 따라서
$N ( 5 ,~3 ) = 60 - 3 cdot 12 + 3 cdot 3 - 1 = 32$
이다.
(2) (가) 거짓이다. $n = 3$ 일 때 (1)에서 $N ( 3 ,~2 ) = 3$ 이다. 한편 $N ( 3 ,~3 )$ 은 상자 $1$ , $2$ , $3$ 에 차례로 카드 $2$ , $3$ , $1$ 또는 $3$ , $1$ , $2$ 를 넣는 $2$ 가지뿐이므로 $N ( 3 ,~3 ) = 2$ 이다. 따라서 $N ( 3 ,~2 ) neq N ( 3 ,~3 )$ 이다. (상자 $n - 1$ 개에 조건에 맞게 넣은 뒤 남은 카드가 $n$ 이 적힌 카드일 수 있기 때문이다.)
(나) 참이다. 상자 $1$ 에 넣는 카드에 적힌 수를 $j$ 라 하면 $j neq 1$ 이다.
(ㄱ) $2 leq j leq k$ 인 경우( $j$ 를 정하는 방법은 $k - 1$ 가지): 상자 $j$ 에 카드 $1$ 을 넣으면, 남은 $k - 2$ 개의 상자에 카드 $1$ , $j$ 를 제외한 $n - 2$ 장의 카드를 조건에 맞게 넣으면 되므로 $N ( n - 2 ,~k - 2 )$ 가지이다. 상자 $j$ 에 카드 $1$ 을 넣지 않으면, 상자 $1$ 을 제외한 $k - 1$ 개의 상자에 카드 $j$ 를 제외한 $n - 1$ 장의 카드를 넣되, 상자 $j$ 에는 카드 $1$ 을, 그 밖의 상자 $i$ 에는 카드 $i$ 를 넣지 않아야 한다. 각 상자마다 넣으면 안 되는 카드가 서로 다른 한 장씩 정해져 있으므로 $N ( n - 1 ,~k - 1 )$ 가지이다.
(ㄴ) $k < j leq n$ 인 경우( $j$ 를 정하는 방법은 $n - k$ 가지): 상자 $1$ 을 제외한 $k - 1$ 개의 상자에 카드 $j$ 를 제외한 $n - 1$ 장의 카드를 넣되 상자 $i$ 에는 카드 $i$ 를 넣지 않아야 하므로 $N ( n - 1 ,~k - 1 )$ 가지이다.
따라서
$N ( n ,~k ) = ( k - 1 ) LEFT { N ( n - 2 ,~k - 2 ) + N ( n - 1 ,~k - 1 ) RIGHT } + ( n - k ) N ( n - 1 ,~k - 1 )$
이고, 정리하면 $N ( n ,~k ) = ( n - 1 ) N ( n - 1 ,~k - 1 ) + ( k - 1 ) N ( n - 2 ,~k - 2 )$ 이다.
(3) (나)에서 $k = n$ 인 경우를 생각하면, $3$ 이상의 모든 자연수 $n$ 에 대하여
$D _{n} = ( n - 1 ) LEFT ( D _{n - 1} + D _{n - 2} RIGHT )$
이다.
$N ( n ,~n - 1 )$ : 상자 $n - 1$ 개에 조건에 맞게 카드를 넣으면 카드가 한 장 남는다. $n$ 이 적힌 상자를 하나 더 놓고 남은 카드를 그 상자에 넣는다고 생각하면, $N ( n ,~n - 1 )$ 은 $n$ 개의 상자에 $n$ 장의 카드를 한 장씩 넣되 상자 $1$ , $2$ , $cdots$ , $n - 1$ 에서는 수가 서로 다르도록 넣는 방법의 수와 같다. 이 중 상자 $n$ 에 카드 $n$ 이 들어가는 방법은 $D _{n - 1}$ 가지, 그렇지 않은 방법은 $D _{n}$ 가지이므로 $N ( n ,~n - 1 ) = D _{n} + D _{n - 1}$ 이다. 위의 점화식에서 $D _{n + 1} = n LEFT ( D _{n} + D _{n - 1} RIGHT )$ 이므로
$N ( n ,~n - 1 ) = {D _{n + 1}} over {n}$
이다.
$N ( n ,~n - 2 )$ : 상자 $n - 2$ 개에 조건에 맞게 카드를 넣으면 카드가 두 장 남는다. $n - 1$ , $n$ 이 적힌 상자를 더 놓고 남은 두 장을 이 두 상자에 넣는 방법은 $2$ 가지이므로, $2 N ( n ,~n - 2 )$ 는 $n$ 개의 상자에 $n$ 장의 카드를 한 장씩 넣되 상자 $1$ , $2$ , $cdots$ , $n - 2$ 에서는 수가 서로 다르도록 넣는 방법의 수와 같다. 이 방법을 상자 $n - 1$ , $n$ 에서 수가 같은지에 따라 나누면, 두 상자 모두 다른 경우 $D _{n}$ 가지, 상자 $n - 1$ 에서만 같은 경우 $D _{n - 1}$ 가지, 상자 $n$ 에서만 같은 경우 $D _{n - 1}$ 가지, 두 상자 모두 같은 경우 $D _{n - 2}$ 가지이다. (단, $n = 3$ 일 때 마지막 경우는 $D _{1} = 0$ 가지이다.) 따라서
$2 N ( n ,~n - 2 ) = LEFT ( D _{n} + D _{n - 1} RIGHT ) + LEFT ( D _{n - 1} + D _{n - 2} RIGHT ) = {D _{n + 1}} over {n} + {D _{n}} over {n - 1}$
이고

$n geq 2$ 이면 $0 < {1} over {n} < 1 = phi ( 0 )$ 이고, $phi ( t _{0} ) < {1} over {n}$ 인 $t _{0}$ 이 존재한다. $phi ( t )$ 는 연속이므로 사잇값의 정리에 의하여 $phi ( u ) = {1} over {n}$ 인 $u$ 가 $0$ 과 $t _{0}$ 사이에 존재하고, $phi ( t )$ 가 감소하므로 이러한 $u$ 는 단 하나이다. 이 값이 $u _{n}$ 이고 $u _{n} > 0$ 이다.

${1} over {2} ln`n + {1} over {2} ln`LEFT ( 2 - sqrt {2} RIGHT ) leq u _{n} leq {1} over {2} ln`n + {1} over {2} ln`LEFT ( 2 + sqrt {2} RIGHT )$
이다. 각 변을 $ln`n$ 으로 나누면 $n -> infty$ 일 때 양 끝의 식이 모두 ${1} over {2}$ 로 수렴하므로
$lim _{n -> infty} {u _{n}} over {ln`n} = {1} over {2}$
이다.

[문항 2]
$2 n$ 개의 끝점을 두 개씩 짝짓는 방법의 수를 $M _{n}$ 이라 하자. 한 끝점을 정하여 그 짝을 고르는 방법이 $2 n - 1$ 가지이고 나머지 $2 n - 2$ 개의 끝점을 짝짓는 방법이 $M _{n - 1}$ 가지이므로 $M _{n} = ( 2 n - 1 ) M _{n - 1}$ 이고, $M _{1} = 1$ 이므로 $M _{n} = ( 2 n - 1 ) times ( 2 n - 3 ) times cdots times 3 times 1$ 이다. 또 이 계산에서 정해 둔 끝점의 짝이 나머지 $2 n - 1$ 개의 끝점 각각일 확률은 모두 ${1} over {2 n - 1}$ 이고, 그 짝이 정해졌을 때 나머지 $2 n - 2$ 개의 끝점을 짝짓는 모든 방법이 일어날 확률은 같다.
(1) $n = 3$ 일 때 짝짓는 방법은 $M _{3} = 15$ 가지이다.
$N _{3} = 1$ 인 경우: 한 끈의 한 끝점에서 출발하면, 그 짝은 다른 두 끈의 끝점 $4$ 개 중 하나이어야 하고, 이렇게 이어진 끈의 반대쪽 끝점의 짝은 남은 한 끈의 끝점 $2$ 개 중 하나이어야 하며, 남은 두 끝점은 서로 짝이 된다. 따라서 $4 times 2 = 8$ 가지이고 확률은 ${8} over {15}$ 이다.
$N _{3} = 3$ 인 경우는 각 끈의 두 끝점이 서로 짝이 되는 $1$ 가지이므로, $N _{3} = 2$ 인 경우는 $15 - 8 - 1 = 6$ 가지이고 확률은 ${6} over {15} = {2} over {5}$ 이다. (혼자 고리가 되는 끈을 고르는 $3$ 가지와 나머지 두 끈이 하나의 고리가 되는 $2$ 가지의 곱으로 세어도 $6$ 가지이다.)
(2) $n geq 2$ 일 때 한 끈의 한 끝점 $rm A it$ 를 정하자. 고리가 $1$ 개이려면 $rm A it$ 의 짝이 같은 끈의 반대쪽 끝점이 아니어야 하고, 그 확률은 ${2 n - 2} over {2 n - 1}$ 이다. 이때 $rm A it$ 와 그 짝을 묶으면 두 끈이 이어져 하나의 긴 끈이 되므로, 끈 $n - 1$ 개의 끝점 $2 n - 2$ 개를 임의로 짝짓는 상황과 같아진다. 따라서
$p _{n} = {2 n - 2} over {2 n - 1} p _{n - 1}$
이고 $p _{1} = 1$ 이므로
$p _{n} = {2} over {3} times {4} over {5} times cdots times {2 n - 2} over {2 n - 1}$
이다.
자연수 $k$ 에 대하여 $( 2 k ) ^{2} > ( 2 k - 1 ) ( 2 k + 1 )$ 이므로 $LEFT ( {2 k} over {2 k + 1} RIGHT ) ^{2} > {2 k - 1} over {2 k + 1}$ 이고, $4 k ^{2} ( k + 1 ) < k ( 2 k + 1 ) ^{2}$ 이므로 $LEFT ( {2 k} over {2 k + 1} RIGHT ) ^{2} < {k} over {k + 1}$ 이다. $n geq 2$ 일 때 이 부등식들을 $k = 1 ,~2 ,~cdots ,~n - 1$ 에 대하여 변끼리 곱하면
${1} over {3} times {3} over {5} times cdots times {2 n - 3} over {2 n - 1} < p _{n} ^{2} < {1} over {2} times {2} over {3} times cdots times {n - 1} over {n}$
즉 ${1} over {2 n - 1} < p _{n} ^{2} < {1} over {n}$ 이다. $p _{n} > 0$ 이므로
${1} over {sqrt {2 n - 1}} < p _{n} < {1} over {sqrt {n}}$
이다.
(3) $n geq 2$ 일 때 (2)와 같이 한 끝점 $rm A it$ 를 정하자.
$rm A it$ 의 짝이 같은 끈의 반대쪽 끝점이면(확률 ${1} over {2 n - 1}$ ) 이 끈은 혼자 고리 $1$ 개가 되고, 나머지는 끈 $n - 1$ 개의 끝점을 임의로 짝짓는 상황이므로 이 경우 고리의 개수의 기댓값은 $1 + E _{n - 1}$ 이다.
$rm A it$ 의 짝이 다른 끈의 끝점이면(확률 ${2 n - 2} over {2 n - 1}$ ) 두 끈이 이어져 하나의 긴 끈이 되고, 끈 $n - 1$ 개의 끝점을 임의로 짝짓는 상황과 같으므로 이 경우 고리의 개수의 기댓값은 $E _{n - 1}$ 이다.
따라서
$E _{n} = {1} over {2 n - 1} LEFT ( 1 + E _{n - 1} RIGHT ) + {2 n - 2} over {2 n - 1} E _{n - 1} = E _{n - 1} + {1} over {2 n - 1}$
이고 $E _{1} = 1$ 이므로
$E _{n} = sum _{k = 1} ^{n} {1} over {2 k - 1} = 1 + {1} over {3} + {1} over {5} + cdots + {1} over {2 n - 1}$
이다.
함수 $y = {1} over {2 x - 1}$ 은 $x > {1} over {2}$ 에서 감소하므로, 자연수 $k$ 에 대하여
${1} over {2 k - 1} geq int _{k} ^{k + 1} {1} over {2 x - 1} dx$
이고, $k geq 2$ 일 때
${1} over {2 k - 1} leq int _{k - 1} ^{k} {1} over {2 x - 1} dx$
이다. 첫 번째 부등식을 $k = 1 ,~2 ,~cdots ,~n$ 에 대하여, 두 번째 부등식을 $k = 2 ,~3 ,~cdots ,~n$ 에 대하여 각각 변끼리 더하면
${1} over {2} ln ( 2 n + 1 ) = int _{1} ^{n + 1} {1} over {2 x - 1} dx leq E _{n} leq 1 + int _{1} ^{n} {1} over {2 x - 1} dx = 1 + {1} over {2} ln ( 2 n - 1 )$
이다. $n geq 2$ 일 때 각 변을 $ln`n$ 으로 나누면
${ln`n + ln`LEFT ( 2 + {1} over {n} RIGHT )} over {2 ln`n} leq {E _{n}} over {ln`n} leq {1} over {ln`n} + {ln`n + ln`LEFT ( 2 - {1} over {n} RIGHT )} over {2 ln`n}$
이고, $n -> infty$ 일 때 양 끝의 식이 모두 ${1} over {2}$ 에 수렴하므로
$lim _{n -> infty} {E _{n}} over {ln`n} = {1} over {2}$
이다.

[문항 1]
먼저 다음 사실을 정리해 둔다. 탄젠트함수는 열린구간 $LEFT ( 0 ,~{pi} over {2} RIGHT )$ 에서 증가하므로, 이 구간의 두 각은 탄젠트값이 같으면 서로 같다. 또 $m < n$ 이면 ${1} over {m} > {1} over {n}$ 이므로 $theta _{m} > theta _{n}$ 이다. 특히 모든 자연수 $n$ 에 대하여 $0 < theta _{n} leq {pi} over {4}$ 이다.
(1) (가) 참이다. $alpha = theta _{n + 1} + theta _{n ^{2} + n + 1}$ 이라 하면 $0 < alpha < {pi} over {2}$ 이고, 덧셈정리에 의하여
$tan alpha = {{1} over {n + 1} + {1} over {n ^{2} + n + 1}} over {1 - {1} over {( n + 1 ) ( n ^{2} + n + 1 )}} = {n ^{2} + 2 n + 2} over {n ^{3} + 2 n ^{2} + 2 n} = {1} over {n}$
이다. 따라서 $alpha = theta _{n}$ 이다.
(나) 거짓이다. $0 < theta _{2 n} < {pi} over {4}$ 이므로 $0 < 2 theta _{2 n} < {pi} over {2}$ 이고
$tan 2 theta _{2 n} = {2 cdot {1} over {2 n}} over {1 - {1} over {4 n ^{2}}} = {4 n} over {4 n ^{2} - 1} > {4 n} over {4 n ^{2}} = {1} over {n} = tan theta _{n}$
이다. 따라서 모든 자연수 $n$ 에 대하여 $2 theta _{2 n} > theta _{n}$ 이므로 $theta _{n} = 2 theta _{2 n}$ 인 자연수 $n$ 은 존재하지 않는다.
(2) $p = q = 1$ 이면 $theta _{p} + theta _{q} = {pi} over {2}$ 이므로 $theta _{n}$ 과 같을 수 없고, 이때 $( p - n ) ( q - n ) = ( n - 1 ) ^{2} neq n ^{2} + 1$ 이다. 따라서 이 경우 두 조건은 모두 성립하지 않는다.
그 밖의 경우에는 $pq geq 2$ 이고 $0 < theta _{p} + theta _{q} < {pi} over {2}$ 이다. (두 각이 모두 ${pi} over {4}$ 이하이고 적어도 하나는 ${pi} over {4}$ 보다 작다.) 덧셈정리에 의하여
$tan ( theta _{p} + theta _{q} ) = {{1} over {p} + {1} over {q}} over {1 - {1} over {pq}} = {p + q} over {pq - 1}$
이므로, $theta _{n} = theta _{p} + theta _{q}$ 인 것은 ${p + q} over {pq - 1} = {1} over {n}$ 인 것과 같다. 이 식은 $pq - np - nq = 1$ , 즉
$( p - n ) ( q - n ) = n ^{2} + 1$
과 같다. 따라서 구하는 필요충분조건이 성립한다.
$n = 7$ 이면 $( p - 7 ) ( q - 7 ) = 50$ 이다. $p leq 7$ 이면 $theta _{p} geq theta _{7}$ 이므로 $theta _{p} + theta _{q} > theta _{7}$ 이 되어 조건에 맞지 않는다. 따라서 $p - 7$ 과 $q - 7$ 은 모두 자연수이고 $p - 7 leq q - 7$ 이므로
$( p - 7 ,~q - 7 ) = ( 1 ,~50 ) ,~( 2 ,~25 ) ,~( 5 ,~10 )$
이다. 따라서 구하는 순서쌍은 $( 8 ,~57 )$ , $( 9 ,~32 )$ , $( 12 ,~17 )$ 이다.
(3) 먼저 $p$ 의 범위를 좁힌다.
$p = 1$ 이면 $theta _{p} + theta _{q} + theta _{r} > theta _{1} = {pi} over {4}$ 이므로 조건에 맞지 않는다.

이므로 점 $rm C it$ 도 $K$ 위에 있다. $K$ 의 방정식은 $t _{1}$ , $t _{2}$ , $t _{3}$ 에 대하여 대칭이므로 두 점 $rm A it$ , $rm B it$ 도 $K$ 위에 있다. $K$ 는 한 직선 위에 있지 않은 세 점 $rm A it$ , $rm B it$ , $rm C it$ 를 지나므로 원이고, 삼각형 $rm A B C it$ 의 외접원이다. 따라서 삼각형 $rm A B C it$ 의 외접원은 점 $rm F it$ 를 지난다.
(3) 삼각형 $rm A B C it$ 가 정삼각형이면 외심과 수심이 일치한다. (2)에서 수심을 $rm H it ( - 1 ,~h )$ 라 하면 외접원의 중심이 $rm H it$ 이고 외접원이 점 $rm F it ( 1 ,~0 )$ 을 지나므로, 외접원의 반지름의 길이 $R$ 는
$R = overline {rm H F it} = sqrt {4 + h ^{2}} geq 2$
이다. 정삼각형의 한 변의 길이는 $sqrt {3} R$ 이므로 넓이는

따라서 구하는 최솟값은 $3 sqrt {3}$ 이다.
